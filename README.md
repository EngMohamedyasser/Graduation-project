# Smart Garage & Safety Monitoring System
Embedded C firmware for ATmega32 AVR microcontroller implementing a smart garage 
and environmental safety monitoring system.

## Features
- Automated garage door control with increment/decrement logic
- Bluetooth communication for remote control
- Temperature sensor monitoring via ADC
- Smoke/gas sensor detection with alerts
- LCD display for real-time status
- Interrupt-driven architecture

## Hardware
- Atmel ATmega32 AVR microcontroller
- Bluetooth module
- Temperature sensor (ADC-based)
- Smoke sensor
- HD44780 LCD display
